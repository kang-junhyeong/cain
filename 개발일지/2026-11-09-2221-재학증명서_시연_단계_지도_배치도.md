# 재학증명서 시연 단계 지도·배치도

- 일시: 2026-11-09 22:21
- 작성자: kang-junhyeong
- 커밋 메시지: feat: 재학증명서 시연 단계에 구글맵·2층 배치도 길찾기·키오스크 이미지 추가

## 작업 내용
- 시연(학생회관 무인발급기에서 재학증명서 발급)에 맞춰 재학증명서 안내 단계를 4단계로 재구성
  1. 학생회관으로 이동 — 구글맵 + 현재 위치에서 도보 경로(TMAP)·소요 시간 표시
  2. 2층 무인발급기 찾아가기 — 2층 배치도 위에 현위치(파란 점) → 무인발급기(빨간 점) 경로를 움직이는 점선으로 표시, 탭하면 전체 화면 확대
  3. 무인발급기에서 증명서 종류 선택 — 키오스크 화면 이미지 추가
  4. 증명서 수령 — 유지
- 기존 3단계 "학생증 또는 신분증 투입" 삭제
- `cain/` 폴더를 main 기준으로 교체하면서 빠졌던 구글맵·도보 경로 코드(`fb7463c`)를 새 폴더 구조로 복원
- 모델 필드는 변경하지 않음: 지도·배치도는 단계 ID(`step_enroll_01`, `step_enroll_02`)로 화면에서 연결, 건물 정보는 GuideViewModel에서 서비스의 buildingId로 로드
- 학생회관 좌표: 플러스 코드 Q77M+95 → 36.763438, 127.282938
- 무인발급기 위치 문구를 1층 → 2층으로 수정 (같은 발급기를 쓰는 다른 증명서 서비스 포함)
- 2층 배치도 사진은 원근 보정해서 `student_union_2f.jpg`로 저장 (원본 사진은 앱 에셋에 등록하지 않음)

- `cain/lib/widgets/step_route_map.dart` — 구글맵 + 도보 경로 위젯 (fb7463c에서 복원)

- `cain/assets/data/services.json` — 재학증명서 단계 재구성, 무인발급기 2층으로 수정
- `cain/assets/data/buildings.json` — 학생회관 좌표 입력
