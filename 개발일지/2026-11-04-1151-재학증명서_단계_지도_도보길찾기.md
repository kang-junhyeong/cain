# 재학증명서 단계 지도·도보 길찾기

- 일시: 2026-11-04 11:51
- 작성자: kang-junhyeong
- 커밋 메시지: feat: 재학증명서 이동 단계에 구글맵 + 도보 경로 표시

## 작업 내용
- 재학증명서 1단계(학생회관 이동)에 앱 내 구글맵 표시
  - 학생회관 마커 표시, 우측 하단 현재 위치 버튼
  - 버튼 → 위치 권한 요청 → 허용 시 현재 위치 + 도보 경로(파란 선) + 예상 시간·거리 표시
  - 경로 끝~건물 사이 남은 구간은 점선 표시
  - GPS 꺼짐 / 권한 거부 / 영구 거부 / 경로 실패 시 안내 및 설정 이동
- 도보 경로는 TMAP 보행자 경로 API 사용
  - 이유: 2026-10 기준 한국 구글맵은 도보 길찾기 미지원 (2026-02 지도 반출 조건부 허가, 기능 출시 미정)
  - TMAP 앱으로 캠퍼스 내 도보 경로가 정상 안내되는 것 확인
  - `WalkingRouteService` 인터페이스로 분리 → 추후 구글 Routes API로 교체 가능
- `GuideStep` 모델에 선택 필드 `buildingId` 추가 (단계별 지도 표시 여부를 데이터로 지정)
- API 키는 `cain/env.json`(Git 제외)에서 관리, `env.example.json` 양식 추가
