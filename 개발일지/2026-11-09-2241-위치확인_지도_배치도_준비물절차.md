## 작업 내용
- 서비스 상세·방문 전 준비 화면의 '위치 확인' 버튼이 "지도 준비 중" 스낵바만 띄우던 것을 건물 위치 지도 화면으로 연결
  - 새 화면 `BuildingLocationScreen`: 건물명 + 상세 위치 + 구글맵(현재 위치 → 건물 도보 경로·소요 시간)
  - 1단계에서 쓰던 `StepRouteMap` 위젯 재사용
  - 서비스에 건물이 없거나 좌표가 없으면 "위치 정보 준비 중" 안내
- 재학증명서 2단계 배치도를 학생회관 층별 안내 이미지(`assets/map/진짜.png`)의 2F 크롭본으로 교체
  - 경로: 2층 엘리베이터 앞 복도(현위치) → 가로 복도 오른쪽 끝(무인발급기, 시연용 임의 위치)
  - 벽을 관통하지 않도록 미리보기로 좌표 확인 후 확정
- `ServiceModel`에 `checklist` 필드 추가 → 재학증명서 준비물 체크리스트는 '학생증'만 표시
  - checklist가 없는 서비스는 기존 requirements 문구를 한 항목으로 사용
- 방문 전 준비 화면: 체크리스트 아래에 번호 붙은 '절차'(단계 이름 목록) 섹션 추가
