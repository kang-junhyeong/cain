## 작업 내용
- 실기기에서 adb로 앱 화면 스크린샷 11장 촬영 (홈 → 재학증명서 전 과정 → AI 도우미)
- 대회용 소개서 PDF 제작 (HTML 작성 → Edge headless로 PDF 변환)
  - 구성: 표지 / 문제 / 솔루션 / 시나리오 1(출발 전·현장) / 시나리오 2(AI 상담) / 차별성 / 기술·확장성 / 기대효과·로드맵·팀
  - 스크린샷은 상태바·내비게이션 바를 잘라 폰 프레임에 배치
  - AI 상담은 "시연용 시나리오, 예시 정보"임을 문서에 명시
- 시연 영상 2편 제작 (ffmpeg 설치 후 합성)
  - 팀이 녹화한 원본(65.mp4 재학증명서, 67.mp4 AI 상담)에 장면별 자막·타이틀 카드 합성
  - 자막 프레임은 HTML → Edge 캡처(`gen_frames.js`), 합성은 `build_videos.sh`
  - 화면 전환 시점을 장면 감지로 측정해 자막과 0.1초 이내로 맞춤, 타이핑 구간은 2~4배속

## 변경 파일
- `기획/Cain_소개서.pdf`, `기획/pdf/` — 소개서와 원본 HTML·이미지

- `기획/65.mp4`, `기획/67.mp4` — 원본 녹화
- `기획/video_work/gen_frames.js`, `build_videos.sh` — 영상 제작 스크립트

- 영상 프레임 시트로 장면·자막 일치 확인
