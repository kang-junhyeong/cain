## 3. 구현 완료 (실기기 동작 확인)

### 재학증명서 발급 안내 — 대표 시나리오
- **서비스 상세 → 위치 확인**: 현재 위치에서 학생회관까지 도보 경로와 소요 시간 표시 (Google Maps + TMAP 보행자 경로 API)
- **방문 전 준비**: 준비물 체크리스트(학생증) + 4단계 절차 미리 보기
- **1단계 학생회관으로 이동**: 단계 화면 안 지도, 현재 위치 버튼 → 도보 경로
- **2단계 2층 무인발급기 찾기**: 층별 배치도 위에 현위치 → 발급기 경로를 점선으로 표시, 탭하면 전체 화면 확대
- **3단계 증명서 선택 / 4단계 수령**: 발급기 화면 형태의 안내 이미지
- **완료 화면**: 후속 확인사항 안내

### 공통 기능
- 4개 언어(한·영·중·벵골) 메뉴·안내·단계 설명 전환
- 위치 권한 요청, GPS 꺼짐·권한 거부·경로 조회 실패 처리
- 데이터 구조: 서비스·단계·건물·연락처를 JSON으로 관리, Repository로 화면과 분리
- 구조: Provider 기반 MVVM (Screen → ViewModel → Repository)
- AI 서버 연결 코드: `POST /api/v1/chat` 요청(질문 + 언어 + 현재 서비스·단계 맥락), 오류·시간 초과 처리 — 실행 옵션 `CAIN_API_BASE`만 넣으면 실제 서버로 전환

## 4. 임의 구현 · 시연용 (실제 정보·기능이 아님)

| 항목 | 현재 상태 | 실제로 하려면 |
|---|---|---|
| AI 챗봇 답변 | 질문 키워드로 고르는 **고정 대화 시나리오** (학생증 분실 → 재발급 → 도서관). 그 외 질문은 서비스 이름이 있으면 위치·운영시간을 정해진 문장으로 답변 | FastAPI 서버 + AI 연동, 검수된 교내 자료 기반 답변 |
| 챗봇 속 교내 정보 | 학생지원팀 학생회관 1층, 041-123-4567, 재발급 5,000원·3~5일, 모바일 학생증 QR 등 **모두 가상 정보** | 담당 부서 확인 후 교체 |
| 무인발급기 위치 | 2층 배치도의 **복도 오른쪽 끝은 시연용 임의 위치** | 현장 확인 후 좌표 수정 |
| 2층 배치도 이미지 | 실사진을 바탕으로 만든 **디자인 시안** ("실제 배치 확인 필요") | 실제 배치와 대조 |
| 3·4단계 발급기 이미지 | 안내용으로 만든 이미지 (실제 발급기 화면과 다를 수 있음) | 실제 화면 촬영 후 교체 |
| 서비스 데이터 | 6개 서비스 모두 검수 상태 `pending` (운영시간 등 미검증) | 공식 자료 확인 후 `approved` |
| 학생회관 좌표 | 구글맵 플러스 코드 기준 | 필요 시 실측 보정 |

## 5. 미구현 · 보류

| 항목 | 상태 |
|---|---|
| 캠퍼스 전체 지도 (S06) | 화면 미연결. 학생회관 외 건물(도서관·본관) 좌표 미입력 |
| 다른 건물 층별 배치도 | 학생회관 2층만 적용. 학생통합지원센터 배치도 이미지는 확보만 함(앱 미반영) |

| 학과·온라인 서비스 (S08) | 진입 경로·공식 URL 미입력, 온라인 서비스 단계 데이터 0개 |
| 성적·졸업증명서 | 단계 텍스트만 있음(3단계·2단계), 지도·배치도·이미지 없음 |
| 학생식당 안내 | 단계 텍스트 2개만 있음, 결제 방법(PAYCO 등) 상세 안내 없음 |
| 서비스 상세의 출처·문의처 표시 | 미구현 |
| 백엔드 (FastAPI · AI · 지식 데이터 검수) | 앱 저장소 범위 밖 — 담당자 진행 확인 필요 |

## 6. 기획 대비 변경 사항

| 기획 | 변경 | 이유 |
|---|---|---|
| 초기 언어 한국어·영어 우선 | 4개 언어 동시 적용 (중국어·벵골어 추가) | 주요 사용자인 유학생 국적 반영 |
| 고정 문구 다국어: ARB/intl | `AppStrings` 클래스로 직접 관리 | 4개 언어 문구를 한 파일에서 빠르게 관리 |
| 지도: 건물 위치 표시 | **TMAP 보행자 경로 API** 추가 → 도보 경로·소요 시간 | 건물까지 실제 길안내가 필요 |
| 실내 안내: 도면 + 상대 좌표 마커 | 기획안대로 적용 + 경로 점선·전체 화면 확대 | — |

> 보안 메모: TMAP 키는 현재 앱 실행 옵션으로 주입합니다. 정식 배포 시에는 서버를 거쳐 호출하도록 바꿀 예정입니다.
